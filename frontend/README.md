# Frontend

The Next.js website for the NFL Season Simulator. See the [project README](../README.md) for what it does and how to run it, and [DEPLOY.md](../DEPLOY.md) for hosting.

```bash
npm install
npm run dev     # http://localhost:3000 (expects the API at http://localhost:8000, or set NEXT_PUBLIC_API_URL)
npx tsc --noEmit && npx eslint .
```
